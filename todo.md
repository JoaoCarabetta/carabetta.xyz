# todo — example AI feed

Example AI feed of to-dos. Invented demo cards only — no real personal information. Actions stay in this browser.

This page is a public demo of an AI-surfaced to-do feed, after [Nicolas Bustamante's interface note](https://x.com/nicbstme/status/2109505834439033107), with [ShapeShift](https://shapeshiftui.vercel.app/)-style cards. It is **not** a live personal dashboard. Every card is invented example data. Do not treat names, amounts, Pix keys, flights, or ticket IDs on this page as real.

The interactive HTML is at [/todo](/todo). Actions (copy, dismiss, add) stay in the browser.

## Example cards

### Example: call the open-data working group

- Type: Call
- Chips: Example · Today · Promised follow-up

Demo reason: an agent would surface a promised follow-up from calendar and chat. This card is invented.

### Example: hold a booth at DataConf 2027

- Type: Payment
- Amount: R$ 480,00 (invented)
- Chips: Example · Due 25/10

Demo reason: a fake invoice PDF would be parsed here. Amount, event, and payee are invented.

### Example: compare three tile-host vendors

- Type: Quotes
- Northwind Host — R$ 90/mo (invented)
- Contoso Tiles — R$ 75/mo (invented)
- 3 others — waiting

Demo reason: an agent would collect quotes for static PMTiles hosting. Vendor names and prices are invented.

### Example: Recife → Brasília, 17 Jan

- Type: Flight
- Amount: R$ 640 for 1 (invented)
- Chips: Example · Nonstop 2h10

Demo reason: cheaper than 16 Jan (R$ 812) in this invented sample. No real itinerary exists.

### Example: tract-review ticket EX-1042

- Type: Waiting on
- Owner: Alex Rivera (fictional)
- Chips: Example · Blocked

Demo reason: waiting on a fictional reviewer to approve a census-tract note.
